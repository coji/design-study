# Design Study

自分が毎日作っている画面を教材にして、デザインの判断を学ぶための Mac 用アプリと、その試作や記録。

AI に的確に指示できる「判断する人」になることを目指している。鍛えるのは、問題に気づく目、原因に名前を付ける語彙、どこをなぜどう直すかを言う指示の 3 つで、自分の手で描く力は対象にしていない。

## 何をするアプリか

1. 練習に使う画面を、URL から取り込む。画面は、スクリプトを外した「写し」として手元に固める
2. 気になるところを指して、一言いう（「文字が多い」「なんか弱い」くらいの言葉でよい）
3. AI が、そこを変えた案を 3 つ作る。元のままを 1 つ混ぜて 4 つ並べ、どれが元かは伏せる
4. 大きく見比べて、良いと思うものを選ぶ
5. 選んだ案が何を変えたものだったか、理論と合うのか食い違うのかを知る
6. 選んだ理由を、自分の言葉で一言残す

記録は、1 回 1 フォルダのただのファイル（Markdown、JSON、画像）で残る。溜まった記録は、理論の項目ごとに積まれていく。

AI は講評の相手であって、正解ではない。AI が何かを指摘するときは、理論の段階（知覚の原理、デザインの原則、経験則と指針、流儀）と出どころを添える。

## 動かす

Mac と、Node.js 22 以上、pnpm、git が要る。AI を使うには、ChatGPT の Plus か Pro のプランが要る（API キーは要らない）。

```sh
cd app
pnpm install     # 依存を入れ、Electron と OpenAI の DevKit を用意する（初回は数分かかる）
pnpm dev         # アプリの窓が開く
```

初めて開いたら、右上の「設定」で ChatGPT にサインインし、左上に URL を入れて画面を取り込む。

配るためのアプリ（dmg）を作るには、`pnpm build:mac` を実行する。`app/dist/` にできる。Apple の開発者としての署名と公証はしていないので、開くときに警告が出る。一度開こうとしたあと、「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を選ぶと、開ける。

詳しい作りは `app/README.md` にある。

## 使うときの決まり

**このアプリを、事業のために使ったり配ったりすることはできない。** サインインに使っている OpenAI の DevKit が、非商用ライセンスのためである。個人の学習や実験には使える。詳しくは `THIRD_PARTY.md`。

取り込んだ画面の写しは、手元の学習のために使う。他人のサイトの写しを、公開したり配ったりしない。

## リポジトリの中身

- `app/`: アプリ本体（Electron、React、TypeScript）
- `docs/`: 考え方と経緯。`design-memo.md` が設計メモ、`theory-v0.md` が理論帳の最初の版（アプリは、これを AI に渡す）
- `prototypes/`: アプリを作る前の試作。`01` は静的なページ、`02` はブラウザで動く版で、アプリの元になった
- `lab/`: 設計の前提を確かめるために書いた、下調べの道具
- `AGENTS.md`: コーディングエージェント向けの案内。決まっていること、まだ決まっていないことが書いてある

理論帳の出どころは、AI の記憶で書いたもので、原典での確認はまだしていない。自分の理論にする前に、原典か信頼できる本で確かめること。
